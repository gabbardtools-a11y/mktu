# 🚀 Запуск МКТУ-проекта на VPS SmartApe

Это пошаговая инструкция для запуска сайта на VPS. **Не пугайтесь командной строки** — справится каждый, нужно просто копировать команды и вставлять.

## ⏱ Что нужно сделать (15-20 минут)

1. ✅ Получить IP и пароль от VPS (из письма SmartApe)
2. ✅ Подключиться к серверу по SSH
3. ✅ Загрузить проект и установочный скрипт
4. ✅ Запустить скрипт — он сделает всё сам
5. ✅ Открыть сайт в браузере

---

## 📋 Что у вас должно быть

После заказа VPS вы получите от SmartApe письмо примерно такого вида:

```
Услуга: VPS HDD S1
IP-адрес: 194.32.21.55   ← это ваш IP
Логин: root
Пароль: aB3xK9mN2pQ       ← это ваш пароль
ОС: Ubuntu 26.04 LTS
```

**Запишите эти данные** — они нужны для подключения.

## 🔌 Шаг 1: Подключиться к VPS по SSH

### На Windows 10/11 (самый простой способ)

1. Нажмите **Win + R** на клавиатуре
2. Введите `cmd` и нажмите Enter — откроется чёрное окно
3. Введите команду:
   ```
   ssh root@ВАШ_IP
   ```
   Например: `ssh root@194.32.21.55`
4. При первом подключении спросит «Are you sure you want to continue connecting?» —
   введите `yes` и нажмите Enter
5. Введите пароль из письма
   - ⚠️ **Пароль при вводе не отображается** (даже звёздочек нет) — это нормально
   - Просто введите и нажмите Enter

### На Mac / Linux

1. Откройте **Terminal** (Cmd+Space → введите «terminal»)
2. Введите:
   ```
   ssh root@ВАШ_IP
   ```
3. На вопрос о подтверждении — `yes`
4. Введите пароль (не отображается) и нажмите Enter

### Если не получается подключиться

- Проверьте, что IP и пароль правильные
- Попробуйте скопировать пароль из письма (без пробелов в конце)
- Если SmartApe дал веб-консоль в панели — используйте её

## 📦 Шаг 2: Загрузить проект на VPS

После успешного подключения к серверу вы увидите примерно такое:
```
root@vps:~#
```

Это **приглашение к вводу команд**. Вставьте следующую команду (полностью):

```bash
cd /opt && curl -fsSL -o mktu.zip "https://tmpfiles.org/dl/wTwRT9HwYNlH/mktu-smartape.zip" && unzip -q mktu.zip -d mktu && rm mktu.zip && cd mktu && ls
```

Нажмите Enter. Должно загрузиться и распаковаться. В конце увидите список файлов:
```
Dockerfile  README-SMARTAPE.md  bun.lock  components.json  ...  src  tsconfig.json
```

Если видите `package.json` в списке — всё отлично! ✅

## 🚀 Шаг 3: Запустить авто-скрипт

### Загружаем скрипт:

```bash
curl -fsSL -o /opt/install.sh "https://raw.githubusercontent.com/ZHORDIK/mktu-deploy/main/install.sh" && chmod +x /opt/install.sh
```

> Если GitHub не доступен, скрипт уже есть в архиве проекта. Запускайте локальный:
> ```bash
> bash /opt/mktu/deploy/install.sh
> ```

### Запускаем скрипт:

```bash
bash /opt/install.sh
```

### Что будет происходить

Скрипт начнёт работать — побегут строки. **Не прерывайте** (Ctrl+C).

Шаги скрипта:
1. 📦 Установка Docker (1-2 минуты)
2. 📥 Загрузка проекта (уже сделано, пропустит)
3. 🔨 Сборка Docker-образа (2-4 минуты)
4. 🏃 Запуск контейнера (5 секунд)
5. 🌐 Настройка Nginx (10 секунд)
6. 🔒 Получение SSL-сертификата Let's Encrypt (30-60 секунд)

### Вопросы скрипта

В процессе скрипт спросит 2 вопроса:

**Вопрос 1 — домен:**
```
🌐 Введите домен для сайта (например, mktu.ru)
   или нажмите Enter, чтобы использовать IP-адрес (без SSL):
```

- Если домена нет — **нажмите Enter** (сайт будет по IP, без HTTPS)
- Если домен есть — введите его (например, `mktu.ru`)

**Вопрос 2 — источник проекта:**
```
📦 Откуда загрузить проект?
  1. Из ZIP-архива (по URL) — рекомендую, просто
  2. Из Git-репозитория (нужен public repo)
  3. Проект уже загружен в /opt/mktu
  Введите 1, 2 или 3 [1]:
```

Введите **`3`** и нажмите Enter (мы уже загрузили проект в шаге 2).

## 🎯 Что проверить на сайте

1. ✅ **Главная страница** — открывается, виден заголовок «МКТУ-13 2026»
2. ✅ **Поиск** — введите «кофе», должны отфильтроваться классы
3. ✅ **Карточка класса** — нажмите на любой класс, откроется диалог
4. ✅ **AI-чат** — нажмите кнопку ИИ, задайте вопрос про «кофе» — должен ответить
5. ✅ **Темы** — 4 кнопки тем в шапке, переключаются
6. ✅ **Корзина** — добавьте классы, скачайте RTF
7. ✅ **FAQ** — откройте, должны быть 11 вопросов

Если AI-чат не работает — откройте `http://ВАШ_IP/api/ai-chat`, должно вернуть:
```json
{"ok":true,"service":"mktu-ai-chat","provider":"routerai",...}
```
Если `provider: "routerai"` — всё настроено. Если `provider: "none"` — ключ RouterAI не подхватился (напишите мне).

## 🐛 Если что-то не работает

### Сайт не открывается

```bash
# Проверить, что контейнер работает
docker ps

# Должен быть контейнер "mktu" со статусом "Up"
# Если нет — запустите:
docker start mktu

# Проверить логи приложения
docker logs mktu --tail 50
```

### Ошибка 502 Bad Gateway

```bash
# Перезапустить Nginx
systemctl restart nginx

# Проверить логи Nginx
tail -20 /var/log/nginx/mktu-error.log
```

### AI-чат не отвечает

```bash
# Проверить, что ключ RouterAI подхватился
curl http://127.0.0.1:3000/api/ai-chat
# Должно быть "provider":"routerai"

# Если "none" — пересоберите контейнер
cd /opt/mktu
docker build -t mktu:latest .
docker restart mktu
```

### Порты закрыты

В панели SmartApe проверьте, что порты **80** и **443** открыты (обычно открыты по умолчанию).

## 🌐 Привязка домена (опционально)

Если хотите свой домен (например, `mktu.ru`):

1. **Купите домен** у любого регистратора (Reg.ru, RU-CENTER, Timeweb — от 199 ₽/год)
2. В панели регистратора настройте **A-запись**:
   - Тип: `A`
   - Имя: `@` (или пусто)
   - Значение: IP вашего VPS (например, `194.32.21.55`)
3. Подождите 10-30 минут (DNS обновляется)
4. На VPS запустите:
   ```bash
   sudo certbot --nginx -d mktu.ru
   ```
5. Готово — сайт доступен по `https://mktu.ru` с бесплатным SSL
